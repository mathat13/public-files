# Outcomes

## Summary

The project successfully produced a free, self-hosted dynamic DNS solution capable of automatically maintaining Cloudflare DNS records as the public IP address changes. This removes the need for manual intervention and improves the reliability of externally accessible services hosted on a home network

## Project Outcomes

- Free to operate apart from domain ownership and existing hardware
- Zero manual intervention once set up
- Setup simplified through automation

- Published my first Docker image
- Learned what an implementation of DDNS looks like
